# Contributing to PyGuard Pro

Thank you for your interest in contributing! Please follow these guidelines:

## How to Contribute
- Fork the repository and create your branch from `dev`.
- Write clear, concise commit messages.
- Add tests for new features or bug fixes if possible.
- Ensure your code passes linting and runs on Python 3.8+.
- Open a pull request with a clear description of your changes.

## Reporting Issues
- Use the GitHub Issues tab to report bugs or request features.
- Include steps to reproduce, expected behavior, and screenshots/logs if helpful.

## Code Style
- Follow PEP8 and use descriptive variable names.
- Document functions and classes with docstrings.

## Communication
- Be respectful and constructive in all discussions.
