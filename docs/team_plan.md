# PyGuard Pro Team Plan

## Branching Strategy
- `main`: Stable, production-ready code
- `dev`: Integration branch for new features
- `feature/<feature-name>`: Feature-specific branches (e.g., `feature/packet-capture`)

## Git Workflow
1. Create a new branch from `dev` for each feature or fix.
2. Open a pull request (PR) to merge into `dev`.
3. Code review and testing before merging to `main`.

## Weekly Deliverables Tracking
- Use GitHub Projects or Issues to track tasks and progress.
- Weekly check-ins for status updates and blockers.

## Documentation
- All plans, outputs, and diagrams go in the `docs/` folder.
- Update documentation as features are added or changed.
- **Note:** As of the latest update, all protocol details are now extracted and stored (Wireshark-like), and documentation should reflect these advanced features.

## Communication
- Use team chat or GitHub Discussions for quick questions.
- Weekly meetings for planning and review.
